# 大水果模型素材包

这是一套用于休闲堆叠/三消小程序的原创 3D 风格水果位图素材，共 12 个品类、4 个观察角度。

## 目录

- `turnarounds/`：透明背景多角度周转板，最终验收文件为 `*-clean.png`，适合验收和后续建模参考。
- `sprites/master/`：512×512 透明 PNG 母版，共 48 张。
- `sprites/runtime/`：256×256 透明 WebP 运行时素材，共 48 张。
- `source/`：保留的原始色键背景生成图，便于重新抠图。
- `manifest.json`：品类、角度、尺寸和文件命名清单。

每个品类均提供 `front`、`three-quarter`、`side`、`top` 四个角度。所有图使用统一左上柔光、右下体积暗侧和圆润厚实的休闲游戏风格。

这些文件是多角度 3D 渲染风格位图，不是可旋转的 `.glb`、`.fbx` 或带骨骼网格模型。
