# 消消农场

《消消农场》是一款原创微信堆叠三消小游戏。当前版本已经从规则演示升级为可直接试玩的完整竖屏体验：大盘散堆、多层遮挡、7 格收集槽、双阶段挑战和三个真实可用的局内道具。

## 已实现

- 12 种代码绘制的原创农场物品，无外部图片依赖。
- 第一关“热身小摊”18 个物品，第二关“丰收大堆”48 个物品。
- 高密度椭圆大盘、随机旋转和不同尺寸物品；重叠只影响视觉，点到露出的部分即可直接拿取。
- 点击收集、同类靠拢、三个相同自动消除、7 格占满失败。
- “移出”“凑齐”“打乱”三个每关限用一次的功能道具；移出后的物品会进入可点击的暂存区。
- 首页、关卡进度、提示反馈、第一关过渡、最终胜利和失败重试流程。
- 自动化核心逻辑测试与微信小游戏入口冒烟测试。

## 构建和验证

需要 Node.js 18+ 与 pnpm：

```powershell
pnpm install
pnpm run verify
```

构建结果生成到 `minigame/`。该目录已使用微信开发者工具的测试 AppID 配置，可直接作为“小程序/小游戏项目”导入和编译。

## 操作说明

1. 点击“开始挑战”进入第一关。
2. 所有物品都可以拿取，即使处于下层，只要点到露出的图案就会直接进入槽位。
3. 收集槽中三个相同物品会自动消除；槽位达到 7 格则挑战失败。
4. 第一关清空后进入 48 个物品的第二关。
5. 卡住时可以使用一次移出、凑齐或打乱；暂存物品可以点击放回槽位。

## 目录结构

```text
src/core/GameManager.ts       页面、关卡状态与交互流程
src/game/LevelGenerator.ts    双阶段可解关卡生成
src/game/BlockDetector.ts     重叠关系分析（不锁定点击）
src/game/SlotManager.ts       7 格槽与三消规则
src/ui/CanvasDrawing.ts       12 种原创物品和角色绘制
tests/                        核心逻辑及运行时冒烟测试
config/                       微信小游戏配置模板
```
