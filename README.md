# 消消农场

《消消农场》是一款原创微信堆叠三消小游戏。当前版本提供深盘散堆、7 格收集槽、30 关章节挑战和三个真实可用的局内道具。

## 已实现

- 四套元素均已接入真实材质透明多视角精灵：18 种水果、11 种厨房食材、8 种饮具和 8 种甜品；每种提供 `front / three-quarter / side / top` 四个视角。若图片尚未加载完成，游戏仍会安全回退至 Canvas 绘制。
- 首页可选择“水果菜篮 / 水杯小铺 / 厨房杂货 / 甜品乐园”四套全局元素；选中的一套会覆盖全部 30 关，切换套装不会按章节自动变更。
- 30 个正式关卡，分为“新手农场、丰收田园、疯狂农庄”三章，每章 10 关。
- 第 1 关保留教学密度；第 2 关起进入高密度堆叠（108～330 个物品），物品种类、层数、尺寸、旋转与密度同步提升。
- 物品会打散同类组合并以不规则错位堆进长方体收纳箱；拿走一个后空位沿原有排列传递，邻近物品滑入补位，整层清空后下一层再整体直落一格。
- 盘面按设备高度自适应，物品会限制在盘面内，底部道具和收集槽不会被高密度盘面挤出屏幕。
- 带木质内壁、前景挡板、纵深阴影和横向纹理的长方体收纳箱；仅可点击当前露在最上面的物品表面，遮挡层需先移开。
- 点击收集、同类靠拢、三个相同自动消除、7 格占满失败。
- 关卡计时从点击开始后启动；点击顶部暂停、切到后台或关卡提前结束时冻结，返回后点击继续才恢复累计时间。
- 每次成功点击会播放对应物品音调，无振动反馈。
- “移出”“凑齐”“打乱”三个道具每关各限用 1 次，按钮实时显示剩余次数；移出物品会播放向左下方滑出的退场动画，随后从界面彻底消失。
- 首页、30 关地图、本地解锁存档、逐关过渡、最终胜利和失败重试流程；返回首页后可直接重新挑战最近游玩的关卡。
- 失败后点击重试会从第 1 关重新开始。
- 每次成功点击按物品类型播放对应音调，已移除振动反馈。
- 结算页显示 1～3 星评价，连续 1.8 秒内完成多次三消会形成 Combo 反馈。
- 首页增加每日挑战入口和农场图鉴；图鉴按元素套装累计发现 63 种物品，并保存到本机。
- 失败结算页提供一次激励视频复活入口；未配置广告位时开发者工具使用本地测试奖励，上线前需填入正式广告位 ID。
- 立体渐变按尺寸缓存、补位动画按稳定帧率重绘；自动化核心逻辑测试与微信小游戏入口冒烟测试。

## 构建和验证

需要 Node.js 18+ 与 pnpm：

```powershell
pnpm install
pnpm run verify
```

构建结果生成到 `minigame/`。该目录已使用微信开发者工具的测试 AppID 配置，可直接作为“小程序/小游戏项目”导入和编译。

## 操作说明

1. 首页先选择一套元素；当前选择会贯穿全部 30 关，之后点击“开始第 1 关”或从“30 关地图”进入已解锁关卡。首页主入口固定从第 1 关开始。
2. 所有物品都可以拿取，即使处于下层，只要点到露出的图案就会直接进入槽位。
3. 收集槽中三个相同物品会自动消除；槽位达到 7 格则挑战失败。
4. 清空盘面后解锁下一关，进度自动保存在本机。
5. 点击顶部暂停按钮可冻结计时；返回小游戏后点击“继续游戏”，或选择退出到首页。
6. 返回首页可点击“重新挑战第 1 关”重新开始首关；卡住时可以使用一次移出、凑齐或打乱，移出可让收集槽最前面的至多 3 个物品直接退场。

```text
src/game/LevelGenerator.ts    30 关可解关卡生成
src/game/BlockDetector.ts     重叠关系分析（不锁定点击）
src/game/SlotManager.ts       7 格槽与三消规则
src/ui/CanvasDrawing.ts       63 种物品的真实材质素材接入、回退绘制和角色绘制
tests/                        核心逻辑及运行时冒烟测试
config/                       微信小游戏配置模板
```
